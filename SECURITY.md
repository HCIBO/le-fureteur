# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report vulnerabilities privately through **Security → Report a vulnerability** on this repository (GitHub private vulnerability reporting). Include the affected version, a description of the issue, the steps to reproduce it and its impact.

You will receive an acknowledgement as soon as possible. Once a fix is available, the advisory will be published with credit to the reporter unless you prefer to remain anonymous.

## Scope

In scope: the Le Fureteur web application, its API, the background worker, the `scakit` command-line tool and the deployment files in this repository.

Out of scope: vulnerabilities in third-party dependencies that are already publicly known, findings that require a compromised administrator account, and denial-of-service through excessive traffic.
